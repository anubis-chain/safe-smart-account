# Security policy

## Scope

This repository publishes the Anubis Chain deployment record and a reproducible source snapshot of Safe v1.5.0. The latest revision of `main` is supported.

Report Anubis-specific issues here, including:

- incorrect or compromised deployment addresses
- bytecode or artifact mismatches
- unsafe Anubis integration guidance
- vulnerabilities in the deployment or verification tooling

For a vulnerability that affects the upstream Safe contracts generally, also follow [Safe's security policy](https://github.com/safe-global/safe-smart-account/security/policy).

## Report a vulnerability

Email **anubis.chain@proton.me** with `safe-smart-account` in the subject, the affected contract or file, impact, reproduction steps, and any suggested mitigation.

Do not open a public issue or publish exploit details before the maintainers have had an opportunity to investigate and coordinate a fix. Never send private keys, seed phrases, owner signatures, or production credentials.
